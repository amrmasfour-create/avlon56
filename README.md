# أفلون — دليل الشاشات الخارجية Android للسيارات

موقع ثنائي اللغة (عربي RTL / إنجليزي) لبيع وتركيب شاشات Android الخارجية (Aftermarket): دليل ماركات وموديلات وسنوات وفئات، صفحة لكل سيارة مع مقارنة قبل/بعد، كتالوج شاشات، نظام توافق موثّق، طلبات العملاء مع واتساب، ولوحة تحكم بصلاحيات.

## التشغيل السريع

المتطلبات: **Node.js 22.5 أو أحدث** فقط — لا توجد أي حزم npm خارجية (قاعدة البيانات SQLite مدمجة في Node).

```bash
cp .env.example .env          # عدّل SITE_URL وكلمة مرور المدير
npm run seed                  # إنشاء القاعدة + حساب المدير + الماركات والموديلات
npm start                     # http://localhost:3000   — لوحة التحكم: /admin
```

بيانات تجريبية للعرض (سيارات وشاشات وروابط توافق وهمية): `npm run seed -- --demo`
حذف القاعدة والبدء من جديد قبل الإطلاق: `npm run seed -- --reset`

الاختبارات: `npm test`

## المتغيرات

| المتغير | الوصف |
|---|---|
| `PORT`, `HOST` | منفذ وعنوان الخادم |
| `SITE_URL` | رابط الموقع العام (للروابط القانونية canonical وخريطة الموقع وhreflang) |
| `DB_PATH` | ملف قاعدة البيانات (افتراضي `data/app.db`) |
| `UPLOAD_DIR` | مجلد الملفات المرفوعة (افتراضي `uploads/`) |
| `ADMIN_USER`, `ADMIN_PASSWORD` | أول حساب مدير (يُستخدم فقط إذا لم يوجد مستخدمون) — إن لم تُحدَّد كلمة المرور تُولَّد عشوائياً وتُطبع مرة واحدة |
| `SECURE_COOKIES=1` | عند التشغيل خلف HTTPS |
| `TRUST_PROXY=1` | خلف nginx/Cloudflare لقراءة IP الحقيقي |

## البنية

### نموذج البيانات
- **brands → models → vehicles**: كل «سيارة» = موديل + مدى سنوات + فئة + شكل تابلوه، لأن التابلوه والتجهيزات تختلف بين الفئات والسنوات.
- **screens**: كل مواصفات الشاشة والسعر والعرض والضمان.
- **compat**: ربط شاشة بسيارة مع الحالة (متوافق / متوافق مع تعديلات / غير متوافق)، الإطار، الضفيرة، CANBUS، أزرار المقود، الكاميرا والحساسات، نظام الصوت، التعديلات، تكلفة التركيب.
- **media**: صور وفيديوهات التركيب ومعرض الأعمال.
- **orders, articles, faqs, search_log, users, sessions, settings**.

## الجودة والأمانة (البند 10)
- لا يظهر أي ربط توافق في الموقع إلا إذا كان `verified = 1`، ولا يمكن تفعيل التحقق دون إدخال الإطار والضفيرة، ويُسجَّل من قام بالتحقق ومتى.
- «متوافق مع تعديلات» يتطلب كتابة التعديلات المطلوبة.
- نسخ روابط التوافق من سيارة لأخرى ينشئها **غير موثّقة** حتى يُتحقق منها.
- كل صورة لها نوع: حقيقية أو توضيحية؛ التوضيحية تظهر بعلامة «صورة توضيحية» دائماً.
- وضع العرض (`demo_mode`) يُظهر شريطاً للزوار بأن البيانات تجريبية.

## الأمان وحماية بيانات العملاء
- كلمات المرور بـ scrypt، جلسات بكوكي HttpOnly + SameSite=Strict، رمز CSRF لكل عملية تعديل.
- حد لمحاولات الدخول (10/15 دقيقة) والطلبات (8/ساعة لكل IP) + فخ للروبوتات.
- صور التابلوه من العملاء تُحفظ في `uploads/private` ولا تُعرض إلا للمستخدمين المصرّح لهم بالطلبات.
- فحص نوع الملف من محتواه (JPG/PNG/WEBP/MP4/WEBM فقط)، وسياسة CSP صارمة.
- يمكن حذف بيانات العميل نهائياً من صفحة الطلب.

## SEO
صفحات تُولَّد من الخادم، عنوان ووصف لكل صفحة، روابط canonical وhreflang (ar/en)، `sitemap.xml` و`robots.txt`، بيانات منظمة JSON-LD (Product, BreadcrumbList, ItemList, FAQPage, Article, AutoPartsStore).

## النشر
1. خادم بـ Node 22 (VPS أو Docker)، خلف nginx مع HTTPS.
2. اضبط `.env` (`SITE_URL`, `SECURE_COOKIES=1`, `TRUST_PROXY=1`).
3. `npm run seed` ثم شغّل `npm start` عبر systemd أو pm2.
4. **النسخ الاحتياطي**: انسخ `data/` و`uploads/` يومياً.
5. بعد النشر: سجّل الدخول، غيّر كلمة المرور، أدخل رقم واتساب وبيانات التواصل من «إعدادات الموقع».

مثال Dockerfile:
```dockerfile
FROM node:22-alpine
WORKDIR /app
COPY . .
ENV NODE_ENV=production
VOLUME ["/app/data", "/app/uploads"]
EXPOSE 3000
CMD ["sh", "-c", "npm run seed && npm start"]
```

## الخطوات التالية المقترحة
- استبدال الصور التوضيحية بصور حقيقية للتركيبات.
- إشعار فوري بالطلبات الجديدة (WhatsApp Business API أو بريد).
- عند نمو الكتالوج لآلاف السيارات: الانتقال إلى PostgreSQL (المخطط متوافق تقريباً).
